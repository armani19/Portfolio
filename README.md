# Armani Magnifico — Portfolio

Personal portfolio website for Armani Magnifico, showcasing work in system design, frontend development, and quality assurance.

## Built with

- React
- Vite
- CSS

## Getting started

```bash
npm install
npm run dev
```

The development server will start locally with Vite.

## Available scripts

```bash
npm run dev       # Start the development server
npm run build     # Create a production build
npm run preview   # Preview the production build
npm run lint      # Run ESLint
npm run deploy    # Deploy the dist folder to GitHub Pages
```

## Features

- Responsive mobile-first layout
- Light and dark mode support
- Mobile navigation menu
- Featured projects and experience sections
- Contact links for email, LinkedIn, and GitHub
